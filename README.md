# Unlimited Sampling Exploration

[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.[CONCEPT].svg)](https://doi.org/10.5281/zenodo.[CONCEPT])

## Contents
- [Notebook: unlimited-sampling-b2r2.ipynb](unlimited-sampling-b2r2.ipynb): main exploration and experiments
- [Slides: unlimited-sampling-presentation.pptx](unlimited-sampling-presentation.pptx): presentation of the results

This repository contains an exploration of the paper "Unlimited Sampling Beyond Modulo" (Azar, Mulleti and Eldar, 2025)

It includes the main notebook `unlimited-sampling-b2r2.ipynb` and a cache of the experimental sweep results.
